# PANDORA - אתר תכשיטים

פרויקט זה הוא אתר תדמית לחנות תכשיטים בשם PANDORA. האתר נבנה ב-HTML, CSS ו-JavaScript ומציג דפי קטגוריות של תכשיטים, דף אודות ודף יצירת קשר.

## מבנה הפרויקט

- `HomePage.html` - דף הבית של האתר עם סליידר תמונות ומודעת מבצעים משתנה.
- `pages/` - תיקייה המכילה דפי תוכן נוספים:
  - `about.html` - דף אודות
  - `bracelets.html` - דף צמידים
  - `contact.html` - דף יצירת קשר
  - `earing.html` - דף עגילים
  - `necklaces.html` - דף שרשראות
  - `rings.html` - דף טבעות
  - `style.css` - קובץ ה-CSS שמשמש את האתר
- `image earing/`, `image necklaces/`, `image rings/`, `image_ bracelets/` - תיקיות תמונות עבור קטגוריות התכשיטים והלוגו.

## טכנולוגיות

- HTML
- CSS
- JavaScript

## תכונות עיקריות

- ניווט בין קטגוריות מוצרי תכשיטים.
- סליידר תמונות בדף הבית.
- מודעות מבצעים משתנות בדף הבית.
- תמונות מוצר לפי קטגוריות.

## איך להפעיל

1. פתח את `HomePage.html` בדפדפן.
2. ודא שהתיקיה `pages/` והתמונות נמצאות באותה רמת תיקייה עם קובץ הבית.
3. ניתן לנווט בין הדפים דרך התפריט בראש הדף.
