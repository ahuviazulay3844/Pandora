# 💎 PANDORA – אתר תדמית לחנות תכשיטים

אתר תדמית בעברית (RTL) לחנות תכשיטים, הכולל דף בית עם סליידר ומבצעים מתחלפים, ארבע קטגוריות מוצרים, דף אודות ודף יצירת קשר.
נבנה מאפס ב-**HTML, CSS ו-JavaScript** בלבד, ללא ספריות או פריימוורקים חיצוניים.

## ✨ תכונות עיקריות

- **סליידר תמונות אוטומטי** בדף הבית (JavaScript).
- **פס הודעות מבצעים מתחלף** בראש הדף.
- **תפריט ניווט** בין הקטגוריות: שרשראות, צמידים, טבעות ועגילים.
- **גלריות מוצרים** בכרטיסים עם שם ומחיר לכל פריט.
- **טופס יצירת קשר** עם שדות חובה ובדיקת תקינות מובנית של HTML5.
- **עיצוב מימין לשמאל** המותאם לעברית.

## 🛠️ טכנולוגיות

| טכנולוגיה | שימוש |
|---|---|
| HTML5 | מבנה הדפים והטופס |
| CSS3 | עיצוב, פריסה ואנימציות |
| JavaScript | סליידר והודעות מתחלפות |
